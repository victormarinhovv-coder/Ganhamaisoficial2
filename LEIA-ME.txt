COMO O BOTÃO BAIXAR UM APK DE VERDADE
O APK não dá para criar dentro deste chat. Faça assim:
1) Suba todos os arquivos no Netlify e confira que o site abre
2) No Chrome, abra pwabuilder.com, cole o endereço do site, toque em Start > Package for stores > Android > Generate
3) Baixe o arquivo .apk, renomeie para GanhaMais.apk e suba no Netlify, junto do index.html
4) No index.html, perto do fim, troque  const APK_URL = '';  por  const APK_URL = 'GanhaMais.apk';
5) Suba o index.html de novo. Agora o botão do cartão baixa o APK
Sem o passo 4, o botão usa a instalação do Chrome.

COMO ATIVAR O ENVIO DE VÍDEO PELA GALERIA (1 vez só)
1) Firebase > Storage > Começar (Get started), no projeto ganha-mais-445e8
2) Em Storage > Regras (Rules), cole isto e publique:
   rules_version = '2';
   service firebase.storage {
     match /b/{bucket}/o {
       match /videos/{allPaths=**} {
         allow read: if true;
         allow write: if request.resource.size < 40 * 1024 * 1024 && request.resource.contentType.matches('video/.*');
       }
     }
   }
   Como o app não usa o login do Firebase, qualquer pessoa com o código do site poderia enviar vídeo (limite 40 MB). Se isso te preocupar, use só links.
Sem isso, o botão "Vídeo da galeria" avisa o erro e você pode usar "Colar link".
